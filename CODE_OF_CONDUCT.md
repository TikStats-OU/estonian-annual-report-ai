# Contributor Covenant Code of Conduct

This project adopts the Contributor Covenant, version 2.1. The full text is available at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/> and is incorporated here by reference.

Project maintainers are responsible for clarifying and enforcing the standards of acceptable behavior. To report a concern, use GitHub’s private reporting feature for this repository or contact a repository maintainer privately. Do not include financial documents, personal data, or credentials in a report.
